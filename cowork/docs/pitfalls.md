# WARP VPS Manager 踩坑

- **规则更新与程序更新各自有权威。** v1.4.0 后程序升级保留当前规则，日常规则可从 Google 官方生成；定时开关由 systemd timer 维护，不另加配置字段。
- **地址集合数量会变化。** 2026-09-05 验证的官方快照为 IPv4 303、IPv6 98；这是当时快照，不是未来更新验收条件。应比较 `goog.json - cloud.json` 完整集合与实际内核规则。
- **UDP 可达不证明 WireGuard 已建立。** 安装与重启验收需隧道最近握手、接收字节增长及双栈真实返回；底层 IPv4 对端也可以承载隧道内 IPv6。
- **检测与服务健康是不同结果。** 部分网页响应不足以确认解锁时保留“无法确认”；不因此把已成功的本地安装、规则或服务状态改写为失败，现有命令语义见 [README](../../README.md)。
- **测试网络的 DNS 特征不应进入生产兼容逻辑。** 测试环境存在 fake-IP DNS 时先定位测试网络并记录专用配置，不能将临时地址或补救逻辑固化进项目。
- **一套实机通过不能外推整个矩阵。** 当前实际在线结论来自 Ubuntu arm64 / WireGuard，其余系统/模式继续由 [todo](../todo.md) 跟踪。
